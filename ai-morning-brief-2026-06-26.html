事实报道 过去24小时无同量级新增

主流 AI 搜索入口今天整体平静，没有新的 DeepSeek、Chrome 或 Google Search 级别公开官宣

近一周代表性变化 DeepSeek

DeepSeek 识图模式已在 App 与网页端上线，仍是近一周中国 AI 搜索入口最值得保留的变化之一

事实报道：6 月 18 日公开报道显示，DeepSeek 识图模式已进入网页和 App 端，与快速模式、专家模式并列。今天没有新的同级别官宣，但它仍代表中国头部问答入口继续往多模态检索延伸，值得在今天保留并明确标注日期。

来源：IT之家 发布时间：2026-06-18
近一周代表性变化 Perplexity

Perplexity 把法律检索入口接到数据库、文档和案件系统，继续证明搜索产品在向执行工作台演化

事实报道：Perplexity 宣布 Computer for Counsel 已面向 Pro 与 Max 用户开放，可连接法律研究数据库、文档工具和案件管理系统，并从这些系统中抽取可引用来源。这不是传统网页搜索更新，但属于对话式检索入口进一步向专业工作流深入。

来源：X：Perplexity 发布时间：2026-06-24
事实报道 Google Finance

Google Finance 新版加入 AI 研究工具与自动简报，继续把搜索式问答推向专业信息入口

事实报道：Google Finance 正式上线 Android 应用与投资组合功能，支持通过截图、CSV、PDF 或文字描述创建组合，并使用 AI 研究工具提问资产配置、固定收益影响等问题。这不属于 Google Search 主页改版，但代表 Google 正把对话式检索嵌入更垂直的高频场景。

来源：Google Blog 发布时间：2026-06-25

产品与模型发布

今天最有代表性的产品与模型更新，集中在编程、营销执行、模型路由与视觉生成等高频工作流。
产品发布 OpenRouter

OpenRouter 发布 MCP Server，把模型路由能力继续推向 Agent 工具层

事实报道：OpenRouter 新发布的 MCP 服务器让开发者可通过统一接口连接多模型供应商，并把路由、配额和访问能力暴露给智能体工作流。它意味着模型分发层正从“给 API”进化到“直接成为 Agent 的工具基础设施”。

来源：OpenRouter 发布时间：2026-06-25
产品发布 Runway

Runway 发布 Agent 2.0，主打广告、视频和营销活动的自动生成、测试与优化

事实报道：Runway Agent 2.0 面向营销团队开放，支持从活动概念生成、广告变体测试，到基于 Meta、YouTube、TikTok 或 Google Ads 数据自动生成下一轮待测素材。它代表生成式 AI 产品正在从创意工具继续走向可量化的营销执行系统。

来源：Runway 发布时间：2026-06-25
产品更新 Claude Code

Claude Code v2.1.193 发布，重点继续放在自动模式、遥测与后台命令治理

事实报道：Anthropic 发布 Claude Code v2.1.193，新增 `autoMode.classifyAllShell`、助手响应 OpenTelemetry 日志事件、实时文件路径补全、MCP 认证提示以及后台 shell 内存压力回收等能力。更新方向很明确：继续把编码 Agent 做成可长期运行、可审计的工程工具。

来源：GitHub Releases 发布时间：2026-06-25
产品更新 Midjourney

Midjourney 继续推进 V8 草稿模式，新增随机风格并预览 V8.2

事实报道：Midjourney 一方面开放 `--preview` 提前体验 V8.2，另一方面让 V8.1 草稿模式支持 `--sref random`，可一次探索 24 种随机风格。它不是更高分模型指标，而是更直接提高设计师的探索效率。

来源：Midjourney Updates 发布时间：2026-06-25

这一栏更值得看“能力怎样变成系统”，包括芯片、古卷识别、工作方式变化以及垂直金融场景落地。
技术突破 IBM

IBM 发布亚纳米级芯片技术，直指未来 AI 负载下的晶体管密度和能效问题

事实报道：IBM 宣布 0.7nm 级别芯片技术与三维 nanostack 架构，单芯片集成近 1000 亿个晶体管，性能与能效都较其 2nm 原型有明显提升。对 AI 行业来说，这类进展的意义不在短期商用，而在于继续为更大规模推理和训练预留物理空间。

来源：IBM Newsroom 发布时间：2026-06-25
技术突破 Vesuvius Challenge

赫库兰尼姆古卷首次被完整虚拟解读，机器学习继续证明自己在科学发现中的放大作用

事实报道：研究团队借助高分辨率 X 射线断层扫描和机器学习，首次在不物理展开的情况下完整读取赫库兰尼姆古卷 PHerc.1667。它不属于消费级 AI 产品新闻，但足以说明多模态识别和重建技术正在持续进入传统科研难题。

来源：Scroll Prize 发布时间：2026-06-25
工作流变化 OpenAI

OpenAI 内部数据显示，Codex 已从开发工具外溢到法务、财务和招聘等非工程团队

事实报道：OpenAI 在官方文章中披露，过去十个月里 Codex 在公司内部逐步取代 ChatGPT 成为主要工作工具，Legal、Finance、Recruiting 等团队的输出 token 中，Codex 占比已经超过 85%。这类数据说明智能体产品的核心变化，不只是“更会写代码”，而是开始改写非工程团队的日常工作方式。

来源：OpenAI 发布时间：2026-06-25

Grok 接入券商系统，展示“检索 + 分析 + 动作”一体化的新应用形态

值得关注

今天最清晰的信号是：搜索入口表面平静，但移动端、工作流端和系统底座都在继续提速。

AI 搜索没有大新闻，不代表入口战降温

今天没有 DeepSeek、Chrome、Google Search 级别的新官宣，但 Perplexity、DeepSeek 和 Google Finance 的连续动作说明，入口竞争已经越来越少停留在“搜索框”本身，而是转向谁能把检索、推荐、工具调用和执行动作接成完整工作台。

移动端会成为下一轮智能体渗透的重要加速器

Codex 正式进入 ChatGPT 移动 App，意味着更复杂的长任务代理不再只能靠桌面端驱动。接下来，通知、审阅、批准和文件预览这类“轻控制”能力，可能会成为更多智能体产品的标配。

金融和营销等高价值垂直系统会继续吸走最先落地的 AI 预算

Google Finance、Grok 与 Interactive Brokers、Runway Agent 2.0 都说明，真正高价值的 AI 落地并不一定发生在大众聊天场景，而更可能先发生在金融研究、广告投放和内容生产等可量化 ROI 的流程里。

未来模型竞争会越来越被成本、合规和基础设施能力决定

IBM 的亚纳米芯片、Anthropic 与阿里巴巴的争议、OpenRouter 的 MCP 服务器，都指向同一件事：接下来比拼的不只是模型效果，还有推理成本、治理边界和接入生态。
