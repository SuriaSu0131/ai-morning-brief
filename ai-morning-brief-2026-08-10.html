近一周回看Chrome Android 测试 Gemini 快捷入口

报道时间：2026-08-06 14:37（美国东部时间）

部分稳定版 Chrome Android 用户出现新的底部工具栏，点击 Gemini 图标即可在浏览器内打开对话。报道说明该功能由服务端开关控制，Google 尚未公布全面推送时间。

来源：Android Authority（援引 9to5Google 测试）

近一周回看Google 说明 AI Mode 后续提问会计入 Search Console 常规查询

报道时间：2026-08-06 07:41（美国东部时间）

Google 的 John Mueller 表示，AI Mode 中每次后续提问都会被视为新的查询，展示、位置和点击数据计入 Search Console 常规效果报告；生成式 AI 专项报告仍不提供查询词明细。

来源：Search Engine Roundtable · Google Search Console 帮助

大公司动向

公司公告OpenAI 暂停不符合新控制要求的 Astra 内部活动

发布日期：2026-08-07

OpenAI 称，近期内部评估无法排除 Astra 达到其准备框架中的网络安全“危急”能力阈值。公司已提高模型权重、网络和工具访问控制，并暂停尚未满足强化要求的内部活动。

来源：OpenAI

独家报道阿里下一代 Qwen 开放权重许可拟引入收入分成

报道时间：2026-08-07

路透社援引知情人士称，阿里计划要求下一代 Qwen 开放权重模型的大型商业用户分享部分收入；具体门槛和比例尚未由阿里公开确认。

来源：Reuters

产品与模型发布

产品更新Anthropic 大幅减少 Fable 5 生物类请求误回退

发布日期：2026-08-07

Anthropic 更新 Fable 5 的生物安全分类器，称测试中生物相关请求的模型回退量下降约 85%。日常健康、检验结果理解和教育类问题可更多由 Fable 5 直接处理；病毒学、毒理学和分子设计等双用途专业请求仍会回退至 Opus 5。

来源：Anthropic

产品发布Meta 推出 Muse Code 测试版

发布日期：2026-08-05

Meta 发布终端编程智能体 Muse Code，由 Muse Spark 1.2 驱动，面向大型代码库规划、实现并验证多文件改动；产品目前为测试版。

来源：Meta AI Research · TechCrunch

产品安排Claude Code Auto Mode 将于 8 月 14 日成为部分套餐默认权限模式

公开信息时间：2026-08-08

公开产品信息显示，Pro、Max 和 Team 用户的新会话将默认使用 Auto Mode，用户或管理员仍可选择其他权限设置。该模式用分类器审查危险命令，具体默认范围以正式产品配置为准。

来源：iThinkDifferent · Claude Code 更新汇总

新技术与新应用

能力评估Astra 可能具备自主发现并利用关键系统零日漏洞的能力

发布日期：2026-08-07

OpenAI 对“危急”阈值的定义包括：无需人工介入，在多个加固的真实关键系统中发现并开发各严重级别的可用零日漏洞，或按高层目标完成端到端新型攻击。公司称 Astra 的初步结果已强到无法排除达到该阈值，但评估仍在继续。

来源：OpenAI

安全控制OpenAI 为 Astra 引入全量风险行为监测

发布日期：2026-08-07

OpenAI 称，Astra 的所有智能体应用现已启用风险行为与错位行为监测，监测器检查模型思维链并可触发安全响应；公司还将与政府机构和部分 AI 安全组织开展能力测试。

来源：OpenAI

分类器更新Fable 5 在扩大健康问答覆盖的同时保留双用途边界

发布日期：2026-08-07

Anthropic 重新编写分类器规则并更新训练数据，使日常健康、临床辅助和生物教育请求更少被误拦截；公司同时保留对可能用于专业研究或药物开发的高风险双用途请求限制。

来源：Anthropic
