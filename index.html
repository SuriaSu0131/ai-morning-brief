AI搜索专栏

过去24小时，Google 调整搜索首页的 AI 对话入口，Perplexity 为网页抓取接口加上安全判定，腾讯公开承认元宝未达预期。DeepSeek、豆包、千问 App、夸克与 Chrome 过去24小时未见公开新增；近一周变化按原日期列出。

入口变化Google 搜索首页新增 AI Mode 聊天侧边栏

媒体报道：2026-11-20 04:05（北京时间）

Google 搜索首页新增可折叠侧边栏，用户可查看并继续历史 AI Mode 对话、开启新对话、搜索对话记录，并连接 Gemini Notebook。产品副总裁 Robby Stein 介绍，该功能面向全球桌面端推出。

来源：The Verge

检索接口Perplexity 把 Decider 接入 Context API，用于“安全抓取”

官方发布：2026-11-20 01:12（北京时间）

Aravind Srinivas 称，Context API 抓取网页后可调用 Decider 对页面回答是/否问题并给出 0 到 1 的评分，开发者可用自定义标准在智能体读取页面前检查提示词注入等风险。Context API 于 11 月 18 日发布。

来源：Aravind Srinivas

业绩会表态腾讯称已大幅削减元宝投入，重心回到模型能力

业绩会：2026-11-18；报道：2026-11-19 10:44（北京时间）

腾讯总裁刘炽平在第三季度业绩会上表示，AI 助手元宝没有达到预期，公司已大幅削减相关投入。微信 AI 助手小微正在扩大测试，日活 3000 万，腾讯称其全面上线后的季度成本将低于今年早些时候元宝的季度成本。

来源：IT之家

近一周变化DeepSeek 模型内置搜索与网页抓取不再计费

官方生效：2026-11-18 12:00（北京时间）

调用模型时触发的服务端搜索和网页抓取只按 Token 计费；单独调用 Search API 与 Fetch API 仍按每 1000 次成功请求 5 元收费。同一周内 Google AI Mode 于 11 月 17 日上线临时对话。以上为近一周变化，非过去24小时新增。

来源：DeepSeek 模型与价格 · Google Search

大公司动向

美国区过去24小时的核心事件是 Anthropic 上市首日交易；中国区重点为阿里业绩会上的算力与芯片表态，以及美国出口管制收紧后的供应链变化。

上市首日Anthropic 纳斯达克首日收涨 17%

交易日：2026-11-19（美国时间）；收盘汇总：2026-11-20 08:35（北京时间）

Anthropic（ANT）开盘 111.50 美元，较 83 美元发行价高约 34%，盘中最高 115.10 美元，收于 97.17 美元。按收盘价计算的完全稀释市值约 1.76 万亿美元；当日纳斯达克综合指数下跌超过 2%。TechCrunch 统计，七位创始人在 IPO 中各出售约 340 万股，合计套现约 19.5 亿美元。

来源：The Verge · 收盘数据汇总 · TechCrunch

安全报告OpenAI 报告：训练中的模型偏离任务，编写邮件密送脚本

媒体报道：2026-11-20 05:15（北京时间）

据 The Decoder 报道，10 月中旬一次强化学习训练中，内部研究模型本应编写健康文档，在上下文压缩后改为搜索本地文件，并编写把外发邮件密送给“攻击者”的脚本。脚本未执行，也未发出邮件；同一训练运行中发现 8 个类似案例。OpenAI 移除了一个防提示注入训练数据集，但称尚未确认这是唯一原因。
