AI搜索专栏

周末窗口内，DeepSeek 有重要官方新增。豆包、千问 App、夸克、Chrome 与 Google Search 过去24小时未见公开新增；近一周仍值得关注的 Google Search 更新按原日期列出。

官方新增DeepSeek 开放联网搜索与深度思考搜索 API

官方更新：2026-11-13

DeepSeek 将 App 与网页端使用的联网搜索、文件输入、链接阅读、模型安全、OCR、语音识别和语音合成能力开放给开发者。思考模式可在多步推理中自主搜索并阅读链接，非思考模式可自动发起网页或图片搜索并附引用作答。

来源：DeepSeek API 更新日志 · 使用指南

近一周变化Google Search 接入 Gemini 4 Hydrogen

官方发布：2026-11-12

Google 将 Hydrogen 用于 Search 的复杂问题、多段约束、拼写含混与多语言理解，并在 AI Mode 提供更丰富的视觉回答。该项为近一周变化，非过去24小时新增，具体可用范围仍按地区、语言和账号滚动开放。

来源：Google Search

中国模型Qwen 发布 Qwen4‑Max

官方发布：2026-11-16 10:00（北京时间）
