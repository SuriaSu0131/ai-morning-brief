AI搜索专栏

过去24小时，DeepSeek 调整 API 内置搜索计费，Perplexity 新增网页内容与事件监测接口，美国多个大型学区就 Google Search 的 AI 功能讨论替代方案。豆包、千问 App、夸克与 Chrome 过去24小时未见公开新增；近一周 Google Search 的变化按原日期列出。

计费调整DeepSeek 模型内置搜索与网页抓取不再收费

官方生效：2026-11-18 12:00（北京时间）

DeepSeek 定价页显示，调用模型时触发的服务端搜索和网页抓取不再计费，只按模型 Token 用量计费，适用于联网工具、Anthropic API 与 Responses API 的 web_search 工具。单独调用 Search API 与 Fetch API 仍按每 1000 次成功请求 5 元计费。

来源：DeepSeek 模型与价格 · IT之家

搜索接口Perplexity 推出 Context 与 Monitor API

官方发布：2026-11-19 09:17（北京时间）汇总

Aravind Srinivas 称 Perplexity 近几天上线三项 API：Monitor 提供事件提醒，Orchestrator 按任务在前沿模型与开放权重模型间路由，Context 批量把网页转换为智能体可用内容。开发者账号介绍称 Context 单次最多读取 10 个 URL，价格为每 1000 个 URL 1 美元；他还称 API 业务同比增长 4.3 倍。

来源：Aravind Srinivas · Context API 说明

学校用户纽约、洛杉矶、芝加哥学区考虑弃用 Google Search

媒体报道：2026-11-19 07:18（北京时间）

The Verge 援引《纽约时报》称，Google 表示明年起学校不能只关闭 Gemini 功能而保留 Search，三大学区随后开始评估替代方案。Google 教育副总裁 Chris Phillips 称 Search 与 AI 已深度整合。

来源：The Verge

近一周变化Google Search AI Mode 上线临时对话

官方发布：2026-11-17

临时对话不保存历史、不引用既有偏好，也不影响后续个性化，面向 AI Mode 支持的全部语言在桌面与移动浏览器推出。该项为近一周变化，非过去24小时新增。

来源：Google Search

研究报告OpenAI：编码智能体完成 2–4 小时任务的成功率升至 46%

官方发布：2026-11-18

OpenAI 第二份研究加速报告基于内部测量称，3 月至 10 月，人工需 2–4 小时的任务中智能体自主成功率从 23% 升至 46%，4–8 小时任务从 13% 升至 35%。不同任务差距大：监控训练任务成功率 79%，推理与服务栈编码为 25%。

来源：OpenAI
