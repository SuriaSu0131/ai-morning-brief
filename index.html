AI搜索专栏

过去24小时未见公开新增。 DeepSeek、豆包、千问 App、夸克、Chrome 与 Google Search 均未发布同量级搜索核心功能。以下保留近一周仍值得关注的变化，并明确原始日期。

11月4日国行 Apple 智能开发者 Beta 开放，千问扩展进入实际测试

测试版推送与媒体实测：2026-11-04

iOS 27.3 Developer Beta 1 已向符合条件的国行设备开放 Apple 智能。用户可主动启用千问扩展；本地模型无法完成的复杂请求可在确认后调用千问，部分任务会跳转千问 App。

来源：Apple 中国 · 科创板日报实测

11月3日Google 调整学校账号的 Search 与生成式 AI 管理方式

官方发布：2026-11-03；媒体后续：2026-11-04

Google 将 Guided Learning 引入 Search，并要求学校管理员显式启用学生账号的 Gemini、Gemini Notebook、Gemini in Classroom 与 Google Search。学校若完全关闭相关 AI 服务，也将失去 Google Search。

来源：Google · AP

11月1日DeepSeek Search 与 Fetch API 开始按请求计费

生效时间：2026-11-01

DeepSeek 开发者平台将 Search 与 Fetch API 从免费额度切换为按请求计费。该变化影响将搜索与网页抓取接入智能体或对话式检索产品的开发者成本。

来源：DeepSeek 更新日志

11月5日Perplexity 推出 Teammates，搜索入口扩展为协作智能体

发布时间：2026-11-06 01:05（北京时间）

Perplexity 向 Max 订阅用户开放网页版 Teammates。智能体可使用 Computer tasks、skills、memory 与工具承接任务，彼此协作，并可在 Slack 中联系同事。

来源：Perplexity（X）

产品与模型发布

网络安全模型OpenAI 发布 GPT‑6 Cyber

发布时间：2026-11-05

GPT‑6 Cyber 面向漏洞发现、验证与修复训练。OpenAI 称其 ExploitGym 得分为 48.5%，高于 GPT‑5.6 Cyber 的 32.1%；模型目前通过 Daybreak Red/Blue 向经审核的安全团队分级开放。

来源：OpenAI · 系统卡

开放权重计划Thinking Machines Lab 发布 Inkling 2 Small

发布时间：2026-11-05

Inkling 2 Small 是 594B 总参数、17B 激活参数的 MoE 模型，支持图像输入与可变推理强度。团队计划下周以 Apache 2.0 许可证开放权重；当前基准数字来自项目方与第三方榜单。

来源：Thinking Machines Lab

视频生成Google 推出 Gemini Omni 1.2 Flash

发布时间：2026-11-05

Gemini Omni 1.2 Flash 支持原生生成最长 15 秒视频、多轮对话编辑与更强参考图一致性。Google 将 720p 价格下调 30% 至每秒 0.07 美元，并在 Gemini API 与 Google Cloud 全面开放。

来源：Google

中国开源模型百度开放 ERNIE‑5.5‑Flash‑Base

发布时间：2026-11-05

百度开放 ERNIE‑5.5‑Flash‑Base 预训练终点权重，模型总参数 280B、每个 token 激活 14B，并提供 FP8 与 BF16 两种 safetensors。厂商基准需等待独立复测。

来源：百度文心 · Hugging Face

应用构建Cursor 可从描述直接构建、部署并分享在线应用

发布时间：2026-11-05

Cursor Live Apps 可由云端智能体搭建应用、配置 Postgres、接入 Cursor SSO 并托管部署。发布前会运行确定性与智能体安全检查；功能面向已启用云端智能体的付费计划。

来源：Cursor

企业平台Mistral Studio 增加托管智能体、工作流与应用

发布时间：2026-11-05

Mistral 扩展 Studio，增加托管智能体、工作流、企业上下文、可观测性与评估能力，可部署于云、VPC 或本地，并与 Mistral Large 4 配套使用。

来源：Mistral AI

新技术与新应用

健康筛查Google 用智能手表传感器检测高血压迹象

发布时间：2026-11-05；论文发表于 Nature

AI‑PPG‑ACC‑HTN 使用消费级智能手表的光电容积脉搏波与加速度数据，在无需袖带校准的情况下被动识别持续性高血压迹象。研究结果已用于 Google Health app 的血压趋势功能设计。

来源：Google Research · Nature

科研使用Anthropic 分析 20.7 万次 Claude 科研会话

发布时间：2026-11-05

Anthropic 以隐私保护方法分析 207,049 次 Claude 与 Claude Code 科研会话，并调查 528 名科学家。数据分析约占 Claude 会话三分之一、Claude Code 会话近一半；结果基于消费版套餐样本。

来源：Anthropic Research

协作智能体OpenClaw 发布 Multiplayer 多人共享智能体

发布时间：2026-11-05

OpenClaw Multiplayer 允许多人通过不同设备操作同一智能体、共享上下文，并由共享队列协调请求。项目方称该能力开源、模型无关，可免费自部署。

来源：OpenClaw

开放安全评测Reflection 推出 Project Iris

发布时间：2026-11-05

Reflection 公开 Beam 的安全训练与双轨评测方法，并通过 Project Iris 发布安全研究、评测材料和工具。Beam 的拒答与合规数字来自项目方 Iris Safety Evaluations。

来源：Reflection

世界模型体验World Labs 开放 Frameboy 实时体验

公开时间：2026-11-06 04:21（北京时间）

Frameboy 是 Atlas 自回归世界模型的优化演示，可从云端 GPU 流式传输并以最高 15 fps 实时探索，支持像素级相机控制。该版本目前是在线演示，不等同于完整模型开放。

来源：李飞飞（X） · World Labs
