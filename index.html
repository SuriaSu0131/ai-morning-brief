安全评估OpenAI 与四家独立机构签约开展嵌入式评估

官方发布：2026-11-16

Apollo Research、METR、Transluce 与 Goodfire 将在约定范围内接触模型检查点、源码、训练与评测数据、监控系统和研究人员，分别评估隐蔽违背开发者意图、模型内部机制、强化学习训练中的错位行为和后训练评测覆盖。评估方可独立发布结果，OpenAI 保留机密信息删改与负责任披露延期安排。

来源：OpenAI

平台合作Hugging Face 将语言模型推理路由切换到 OpenRouter

官方发布：2026-11-16

Hugging Face Inference Providers 的语言模型请求改由 OpenRouter 按实时价格、速度和可靠性选择提供商，并在失败时自动重试；现有代码和 Hugging Face token 继续使用。图像、视频与音频生成仍走原有推理提供商。

来源：Hugging Face

诉讼加州总检察长就智能体网络安全事件起诉 OpenAI

官方诉状与媒体报道：2026-11-16

加州总检察长 Rob Bonta 在旧金山高等法院起诉 OpenAI，指控其模型测试缺少充分安全和监督措施，并援引 7 月 Hugging Face 事件及另外多起事件。上述为原告指控，案件尚未裁决；OpenAI 对媒体表示已进行透明整改并反对把行业共同问题单独归责于该公司。

来源：California DOJ · Reuters

披露政策Anthropic 将高危漏洞披露窗口缩短到 30 天

官方发布：2026-11-16；新规 2027-01-01 生效

Anthropic 把高危和严重漏洞的协同披露期限从 90 天缩短为 30 天，其他漏洞为 45 天；维护者 15 天未回应时将寻求外部协调。正在被利用的漏洞仍维持 7 天期限，未经人工复核的 AI 扫描结果不适用新规。

来源：Anthropic

中国模型腾讯混元发布 Hy4 flash

官方发布：2026-11-16

Hy4 flash 为 224B 总参数、12B 激活参数的多模态混合专家模型，支持 100 万 token 上下文；腾讯公布的 API 定价为每百万 token 输入 0.5 元、输出 2 元，并表示后续计划开放权重。规格、成本与性能比较均为厂商披露。

来源：腾讯混元

新技术与新应用

编码智能体TokenEconomizer 利用仓库历史降低后续任务成本

研究与开源发布：2026-11-16

UC Berkeley、Microsoft Research 与 Microsoft Security 的开源插件从同一仓库的历史会话提炼微型技能、裁剪未使用工具并识别失败循环，无需修改智能体或底层模型。团队报告在 277 个真实修复任务中成本下降 18.4% 至 30.9%，成功率大体稳定；结果来自其选定任务集。

来源：Microsoft Research · GitHub

评测研究METR 测量模型识别“自己正在接受对齐评测”的能力

研究笔记：2026-11-16

研究用调查型智能体检查 19 个对齐评测与 36 个能力评测环境，发现前沿模型区分两类评测的能力在其数据集中提高；识别线索包括模拟环境和蜜罐式任务特征。该结果说明评测设计需防止被识别，不代表模型在真实部署中必然规避监督。

来源：METR

自动化攻防FBI 警告开源 AI 攻击工具已被用于真实入侵

安全通告与媒体报道：2026-11-16

FBI 通报称，攻击者使用曾开源的自主渗透测试工具 Artex 入侵美国 IT 服务商客户与韩国金融机构，部分攻击从选定目标到攻陷不足三小时；常见入口仍包括弱口令和暴露凭证。开发者转为闭源后，旧版本仍在流传。

来源：FBI 2026 网络安全通告索引 · TechCrunch
