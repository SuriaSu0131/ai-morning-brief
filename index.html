AI搜索专栏

Google Search 过去24小时有重要官方新增。中国区 DeepSeek、豆包、千问 App、夸克与 Chrome 过去24小时未见公开新增；本栏不补写旧变化。

搜索升级Google Search 全球接入 Gemini 4 Hydrogen

官方发布：2026-11-12

Google 将 Gemini 4 Hydrogen 推向 Search，重点更新复杂问题、多段约束、拼写含混与多语言理解，并在 AI Mode 中提供更丰富的视觉回答。功能为全球滚动开放，具体可用范围仍受地区、语言与账号类型影响。

来源：Google Search · Google

检索模型Perplexity 开放 Decider v1.3 与 Flash v1.3

研究与模型发布：2026-11-12

两款开放权重决策模型用于分类、路由、排序和评估；Perplexity 表示其生产系统会用分类头判断是否触发网页搜索，模型也可直接对候选文档逐条评分并重排。权重以 Apache 许可发布，厂商给出的检索分数尚待外部复测。

来源：Perplexity

产品与模型发布

Google 模型Gemini 4 Hydrogen 面向开发者、企业与普通用户开放

官方发布：2026-11-12

Hydrogen 定位快速编码、多模态处理与日常智能体任务，支持四档推理强度；已进入 Gemini API、AI Studio、Gemini for business、Gemini App、Google Search 与部分 Antigravity 订阅入口。厂商性能对比来自 Google 及合作方测试。

来源：Google · 模型卡

开放模型Edge0 开放 145B 与 120B 端侧模型

项目更新：2026-11-13（北京时间）

Edge0 发布由 Qwen3.8‑Flash‑Next 衍生的两款稀疏 MoE 模型、权重与推理工具，官方文档面向 Linux 或 Windows 上的单张 NVIDIA GPU。项目标题使用“本地运行”表述，实际显存、内存和速度需按量化版本与硬件分别核对。

来源：Edge0 / GitHub · Hugging Face

世界模型World Labs 向公众开放 Atlas 工具与开发者 API

产品开放：2026-11-12

Atlas 可由文字、图像、视频与 3D 输入生成或重建场景，并输出关键帧、视频片段和 3D Gaussian splats；用户可通过 Viewfinder、Chisel 等工具编辑或导出结果。底层能力与质量描述来自项目方。

来源：World Labs · Atlas

设计工具Figma 3D Transform 开放测试

产品更新：2026-11-12

Figma Design 新增沿 x、y、z 轴旋转与透视深度设置，支持用 Agent 组合 3D 场景、用 Motion 制作动画，并可在 Dev Mode 复制 CSS 或把设计发送给编码智能体。当前为面向 Full seat 用户的开放测试。

来源：Figma Release Notes · Figma Blog

商务智能体Replit Agent 增加企业采购与 Google Ads 投放

产品发布：2026-11-12

Agent 可通过 Link 与 Visa 为美国 Core、Pro 用户准备一次性采购，并在扣款前等待人工确认；Pro 用户可在全球连接或创建 Google Ads 账号，生成素材、预算与投放方案。采购浏览器会在付款阶段关闭通用浏览与 Shell 权限。

来源：Replit

新技术与新应用

安全研究OpenAI 用自动化红队生成更稳定的对抗训练数据

研究发布：2026-11-12

研究团队扩大攻击模型的测试时算力搜索越狱，并要求攻击在多次重复测试中持续成功，再把样本用于强化学习训练。受控实验覆盖网络与生物等双用途领域；OpenAI 称方法已用于 GPT‑6 Astra 与 Sol 的安全训练。

来源：OpenAI Alignment

中国工程平台阿里云发布全栈 AgenticOps 平台

官方社区发布：2026-11-12

平台把日志、指标、链路、评测和受控执行放在同一套智能体运维链路中，用于异常定位、根因分析与生产变更。当前公开材料以架构与场景介绍为主，实际效果和生产边界仍以用户部署为准。

来源：Alibaba Cloud Community

开源控制面AgentScope Service 开放企业智能体控制面

开源发布：2026-11-12

AgentScope Java 社区开放面向分布式智能体的注册、查询、协调、多租户、可视化调试和编排组件，可接入 Claude、DeepSeek Harness 与 LangChain 等不同形态。项目方将其定位为 Agent 调试与分布式部署基础设施。

来源：Alibaba Cloud Community

生成式界面Google A2UI 1.0 让智能体输出原生交互界面

A2UI 1.0 是生成式 UI 开放协议，智能体描述界面结构，应用用自己的原生组件渲染；首批开放 React、Angular、Lit、Flutter、SwiftUI 与 Jetpack Compose 等渲染器，以及 Python、TypeScript、Dart 智能体 SDK。

来源：Google Developers Blog
