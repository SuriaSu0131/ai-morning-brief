10月31日千问将进入中国版 Apple 智能

发布时间：2026-10-31；开发者测试计划：2026-11-04

Apple 宣布 Apple 智能将随 iOS 27.3 于 12 月在中国大陆推出，并与阿里巴巴合作，让用户可在 Siri、写作工具和视觉智能中选择调用千问；首批功能不包含下一代 Siri AI。

来源：Apple 中国 · 千问 App

11月1日DeepSeek Search 与 Fetch API 开始按请求计费

生效时间：2026-11-01 00:00（北京时间）

DeepSeek 官方文档显示，Search 与 Fetch API 的临时免费期结束，11 月 1 日起按请求计费；通过 DeepSeek Harness、Claude Code 或 Codex 发起的服务端工具调用也适用该规则。

来源：DeepSeek API 文档 · DeepSeek 更新日志

10月29日Chrome 将为第三方搜索引擎显示 AI 对话按钮

报道时间：2026-10-29；近一周条目

据 Search Engine Watch 报道，Google 确认 Chrome 地址栏中的 AI 对话入口将支持第三方默认搜索引擎，而非仅在 Google 为默认搜索时显示。具体支持名单与全面上线时间尚未公布。

来源：Search Engine Watch · Chrome AI 功能页

入口核验豆包、夸克与 Google Search 过去24小时无同量级新增

核验时间：2026-11-02 09:00（北京时间）

豆包与夸克未见可确认的搜索核心功能发布；Google Search 最近一次可追溯的重要 AI 搜索更新仍为 10 月 15 日的 AI Mode 与 AI Overviews 来源入口调整。

入口：豆包 · 夸克更新日志 · Google Search

大公司动向

订阅规则OpenAI 将合并 ChatGPT 与 Codex 用量池

帮助文档更新：2026-10-31；计划自2026年12月起生效

OpenAI 帮助中心写明，Plus、Pro 与 Business 计划的 ChatGPT 和 Codex 将共享同一用量额度，并按 token 计算；Instant 对话不计入该共享池。官方尚未公布精确生效日和各档额度。

来源：OpenAI Help Center · Codex 使用说明

融资报道OpenAI 据报将融资目标下调至约200亿美元

报道时间：2026-10-31

Reuters 援引《金融时报》报道称，OpenAI 最新融资目标由约 300 亿美元下调至约 200 亿美元，目标估值约 1.25 万亿美元。融资规模与条款仍处谈判阶段，OpenAI 未在官网确认。

来源：Reuters · Wall Street Journal

经营披露Sierra 宣布 ARR 超过4亿美元

发布时间：2026-10-30

企业客服智能体公司 Sierra 称，本周年度经常性收入超过 4 亿美元，第三季度新增超过 1.5 亿美元。该数字由公司自行披露，未提供审计报告或客户结构明细。

来源：Sierra

网页控制多家 AI 公司支持共享 robots.txt 训练偏好信号

发布时间：2026-10-30

OpenAI 与 Google 分别宣布支持在 robots.txt 中使用共享控制信号，让网站统一表达基础生成式 AI 训练偏好；Microsoft 与 Anthropic 也表示参与。该信号针对训练用途，不等同于阻止搜索索引或所有抓取。

来源：OpenAI · Google Search Central

研究原型DeepSeek 开源 Super-agent 双层架构原型

公开时间：2026-10-31

DeepSeek Harness 团队公开 dsh-superagent 原型，以 Router 接收事件并分派任务，Worker 在独立会话中持续执行。仓库明确标注这是研究原型，不是正式 DeepSeek 产品，也不等同于内部生产版本。

来源：DeepSeek GitHub · 架构文档

创意平台Figma Weave 将生成与编辑流程做成可复用节点

发布时间：2026-10-31

Figma Weave 以节点连接图像和视频生成、编辑、调色、合成与裁剪，支持多模型并排比较和分支探索；团队可把完整节点图封装为 Weave tool，让其他成员一键复用。

来源：Figma · Figma Help

订阅更新Claude Max 套餐更名为 Max 与 Ultra

发布时间：2026-10-30

Anthropic 将 Max 5x 更名为 Max、Max 20x 更名为 Ultra，月费仍为 100 美元与 200 美元；多数已验证 Ultra 账号取消每五小时限制，但周限额不变，新账号可能暂时保留限制。

来源：Claude 官方账号 · Claude Release Notes

API能力Gemini Computer Use 工具进入正式可用

更新日志日期：2026-10-30

Google 将 Gemini API 的 Computer Use 工具从预览推进至正式可用，覆盖 Interactions API 与 GenerateContent API；开发者可让模型通过屏幕观察与动作调用操作用户界面。

来源：Gemini API 更新日志 · Google Cloud Release Notes
