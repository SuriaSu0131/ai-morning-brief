产品与模型发布

中国旗舰预览阿里开放 Qwen4‑Max Preview 两周限时测试

官方文档更新：2026-11-11 10:00（北京时间）

Qwen4‑Max Preview 支持文本生成、图像与视频理解、深度推理、联网搜索、工具调用和结构化输出，提供 100 万 Token 上下文。当前仅通过 Token Plan 使用，预览于 11 月 25 日 24:00 结束后下线。

来源：Alibaba Cloud Model Studio · 中文文档

中国模型百度发布 ERNIE 5.5 Flash Preview

官方发布：2026-11-11

该后训练预览版总参数 280B、每 Token 激活 14B，支持 100 万 Token 上下文，已在千帆平台提供 API。百度称权重将在 11 月 25 日前以 Apache 2.0 协议开放；演示与性能数字均为厂商测试。

来源：百度文心 ERNIE · 百度智能云千帆

决策模型Google 推出 Gemini Decisions API 与 Gemini Decision 1

官方发布：2026-11-11 18:00（UTC）

新 API 面向 yes/no、选项选择与量表评分等封闭集判断，可让同一份文本、图像、音频、视频或 PDF 输入一次评估最多 1,000 个问题，并返回概率与置信度。150 至 250 毫秒延迟为 Google 测试结果。

来源：Google

语音识别ElevenLabs 发布 Scribe v3 与实时版 v3 Live

官方发布：2026-11-11

Scribe v3 面向录音转写，v3 Live 面向实时语音；两者已成为 ElevenLabs App 默认模型，实时版同时进入 ElevenAgents。准确率对比来自 ElevenLabs 在统一数据集上的内部测试。

来源：ElevenLabs · 更新日志

开放世界模型MBZUAI 研究机构开放 PAN 2 权重、代码与训练方案

官方发布：2026-11-10 至 11-11

PAN 2 根据初始场景和动作描述生成后续视频，用于模拟物体运动与交互结果。IFM 以 Apache 2.0 发布模型权重、训练和推理代码；论文尚标注为即将发布，现阶段结果主要来自项目方评测。

来源：MBZUAI · 技术博客 · IFM

新技术与新应用

科学模型AlphaGenome 2 按细胞类型预测 DNA 变异效应

研究发布：2026-11-11

Google DeepMind 的新模型把细胞类型或状态作为条件输入，用于预测遗传变异对特定人类细胞的影响。非商业研究者可通过 API 使用，商业研究处于小范围预览；准确率结果来自论文与官方评测。

来源：Google DeepMind · 研究社区公告

智能体工程AWS 上线本地 Emulator，公开智能体生成的代码与校验集

官方发布：2026-11-11

AWS Emulator 让 SDK、CLI 和编码智能体在本地或 CI 环境调用 AWS 兼容接口，无需部署云资源。AWS 称全部代码由多组智能体生成，依靠真实服务对照测试、合并门禁和持续发布管线校验；源码以 CC0 公开。

来源：AWS · Amazon 工程说明 · GitHub

多智能体评测Anthropic 发布 MAMUBench 三个多人协作环境

研究发布：2026-11-11

研究团队构建共享 API 预算、诊所日历、团体订餐或旅行、代码合并队列四类环境，测试多个用户各自委托智能体后出现的资源竞争与协调失败，并开放其中三个环境。结论来自受控模拟，不等同于真实组织部署结果。

来源：Anthropic Alignment Science

跨平台开发Expo Exact 让编码智能体跨 Web、macOS、iOS 与 Linux 测试同一应用

开源项目更新：2026-11-10 至 11-11

Exact 以声明式 Contract 描述界面，数据逻辑可用 TypeScript 或 Rust；项目提供统一脚本让智能体构建、运行、截图和测试多个平台。项目仍为早期版本，Android 与 Windows 暂未列入支持平台。

来源：Expo / GitHub · Expo 智能体文档
