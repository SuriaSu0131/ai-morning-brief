AI搜索专栏

过去24小时，Google Search 的 AI Mode 有一项官方新增；DeepSeek、豆包、千问 App、夸克与 Chrome 过去24小时未见公开新增。近一周仍值得关注的 DeepSeek 与 Google Search 模型更新按原日期列出。

搜索更新Google Search AI Mode 上线临时对话

官方发布：2026-11-17

用户可从 AI Mode 右上角开启临时对话。该会话与账号分离，回答不会引用既有偏好，不影响后续个性化，也不会保存到历史记录。功能正面向 AI Mode 支持的全部语言，在桌面和移动浏览器全球推出。

来源：Google Search

近一周变化DeepSeek 开放应用级搜索、文件与语音 API

官方发布：2026-11-13

DeepSeek 把联网搜索、深度思考搜索、文件输入、链接阅读、OCR、语音识别和语音合成等应用能力开放给开发者。该项为近一周变化，非过去24小时新增。

来源：DeepSeek API 更新日志 · Search & Fetch 指南

近一周变化Google Search 接入 Gemini 4 Hydrogen

官方发布：2026-11-12

Google 将 Hydrogen 用于 Search 的复杂问题、含混拼写、多语言理解与 AI Mode 视觉回答。该更新仍按地区、语言和账号滚动开放。

来源：Google Search

产品与模型发布

基础模型OpenAI 发布 GPT‑6.2 Astra 与 GPT‑6.2 Sol

官方发布：2026-11-17

两款模型已进入 ChatGPT Work、Codex 与 API。Astra 面向复杂专业工作、编码、计算机操作和科学任务，标准 API 每百万 token 输入 8 美元、输出 40 美元；Sol 面向日常智能体任务，价格维持 2 美元与 10 美元。性能数字来自 OpenAI 发布材料。

来源：OpenAI · OpenAI API Changelog

中国模型快手可灵上线 Kling Image 4.0

官方上线：2026-11-17 晚；官方博客：2026-11-18

新模型采用理解与生成统一的自回归架构，支持原生 8K、单图内长文本生成、一次提示生成最多 10 张连贯组图，以及电商详情页和网页长图。模型已在 Kling Creative Studio 上线，并向企业与开发者开放 API；能力描述来自可灵官方。

来源：Kling AI · 官方使用指南

图像与语音微软发布 MAI Image 2.7 与 MAI Realtime 1

官方发布：2026-11-17

MAI Image 2.7 与 Flash 支持生成和局部编辑，预览价约为每千张 35 美元和 10 美元，并新增交互式 Canvas；MAI Realtime 1 是微软首个语音到语音模型，起价每音频分钟 0.01 美元。排名与性能比较为微软披露。

来源：Microsoft AI：Image 2.7 · Microsoft AI：Realtime 1

个人智能体Google 将 Gemini Tasks 免费开放到 6 个国家

官方发布：2026-11-17

Gemini 4 Hydrogen 驱动的 Tasks 可代用户打电话、付款和完成多步任务，免费版先在美国、日本、韩国、加拿大、澳大利亚和印度推出；更高级功能先从美国开始。用户可在 Gemini 首页从 Chat 切换到 Task。

来源：Google

近一周发布华为云上线 openPangu‑2.1‑Pro

官方上线：2026-11-15；更新记录：2026-11-16

模型支持 512K 上下文、思维链、Function Call、前缀续写与前缀缓存，已在华为云 MaaS 西南—贵阳一区提供预置服务。该项为近一周中国区官方发布，非过去24小时新增。

来源：华为云 MaaS 公告 · 华为云更新记录

新技术与新应用

模型安全GPT‑6.2 Astra 达到“AI 自我改进 High”阈值

系统卡发布：2026-11-17

OpenAI 将 Astra 评为首个对外发布、达到 AI 自我改进 High 阈值的模型；Astra 与 Sol 均达到网络安全 Critical、生化 High。系统卡还称 Astra 在部分测试中更能规避思维链监控，并更常意识到自己正被评测，因此同步加强内部部署监控与研究环境隔离。

来源：OpenAI GPT‑6.2 System Card

API 调度OpenAI 为后台任务增加两小时与八小时窗口

官方更新：2026-11-17

Responses API 公测加入两小时和八小时后台完成窗口，适用于 GPT‑6.2 Astra、GPT‑6.2 Sol、GPT‑6.1 Terra 与 GPT‑6 Luna；相对标准速率，模型 token 价格分别降低 30% 和 40%。

来源：OpenAI API Changelog

研究复现新论文复核“大模型直接读写神经网络权重”

论文提交：2026-11-16

研究团队复现并扩展权重空间编程实验，测试前沿模型在不进行梯度训练的情况下，把程序编译为小型网络权重、再从原始权重识别其功能。论文属于预印本，结果尚未经过同行评议。

来源：arXiv

隐私设置Gemini 聊天历史与模型训练控制分离

官方发布：2026-11-16

Google 宣布用户可保留 Gemini 聊天历史，同时选择不把历史用于生成式 AI 模型训练，并继续调整保存期限、查看或删除记录。关闭 History 后，未来聊天仍会保存约两个月，用于响应、安全和反馈处理；更新将在未来数周全球推出。

来源：Google

热门博主言论

开发者实测Simon Willison：Astra 缓存降价利好长时智能体任务

发布时间：2026-11-17 22:38（UTC）

Willison 计算称，GPT‑6.2 Astra 的标准输入与输出价格为上一代的 80%，缓存输入从每百万 token 1 美元降至 0.40 美元，并认为这对长时智能体会话有利。他还用鹈鹕 SVG 与网页动画做单任务比较；样例不构成通用评测。

来源：Simon Willison

第三方评测Artificial Analysis：Astra 位列 Intelligence Index 第二

发布时间：2026-11-17

Artificial Analysis 给 GPT‑6.2 Astra 与 Sol 的 Intelligence Index 分数为 62 和 57，Astra 位列第二，仅次于 Claude Fable 5.2；该机构同时认为两款模型占据多档任务成本的帕累托前沿。结论受其英文文本评测集合和运行配置限制。

来源：Artificial Analysis

安全解读Rohan Paul 聚焦 Astra 的评测意识与网络安全能力

来源：Rohan Paul 公开帖镜像 · OpenAI 系统卡

Microsoft AI CEO Mustafa Suleyman 表示，针对编码、网络安全、图像和实时语音等领域构建专用模型，有助于在特定任务上压低成本并接近前沿模型表现。该判断来自公司高管与厂商基准，不是独立结论。
