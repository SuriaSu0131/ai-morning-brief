AI搜索专栏

过去24小时未见 DeepSeek、豆包、千问 App、夸克、Chrome、Google Search 公开发布同量级新增；以下保留近一周内仍值得关注的变化，并标注日期。豆包、千问 App、夸克过去24小时未见公开官方新增。

事实Google Search 的 AI Mode 开始接入更多第三方应用

发布日期：2026-07-16

Google 公布 AI Mode 将在美国开始支持连接 Instacart、Canva、YouTube Music 等服务，用户可直接在搜索结果页内加购物车、做设计或生成播放列表。

来源：Google Blog

事实DeepSeek 旧模型名已按计划退出，搜索与 Agent 接入开始统一到 V4

发布日期：2026-04-24；生效时间：2026-07-24 15:59 UTC

DeepSeek 官方文档说明，`deepseek-chat` 与 `deepseek-reasoner` 已退役，接入方需切换到 `deepseek-v4-pro` 或 `deepseek-v4-flash`；V4 同时强调 1M 上下文和 Agent 能力。

来源：DeepSeek API Docs

事实Qwen Code 周更重新加入内建 `web_search`

发布日期：2026-07-23

Qwen Code 07-23 周更恢复了内建 `web_search`，并把网页阅读与来源引用重新做回默认能力。千问 App 过去24小时未见公开新增，但阿里系在“对话式检索+代码代理”方向继续推进。

来源：Qwen Code Docs

大公司动向

事实Anthropic 扩大与 Cognizant 的合作，把 Claude 推向更多企业客户

发布日期：2026-07-27

Anthropic 说 Cognizant 已在制造、生命科学、保险等行业用 Claude 搭建系统，双方新合作包括把 Claude 嵌入 Cognizant 自身平台，并扩展 Claude 认证劳动力。

来源：Anthropic

事实OpenAI 发布新一篇职场研究，继续把企业采用作为主线

发布日期：2026-07-27

OpenAI Economic Research 基于 80 多万条美国 ChatGPT 使用消息称，43.5% 的“职业特定”AI 使用已经跨出了原本岗位边界，重点强调 AI 正在重排企业内部分工。

来源：OpenAI

产品与模型发布

事实OpenAI Health 在美国开始向 ChatGPT 用户开放

发布日期：2026-07-23

OpenAI 宣布美国 18 岁以上登录用户可在 ChatGPT 里连接 Apple Health 与支持的医疗记录，让模型基于个人健康数据做连续问答、结果对比与就诊准备。

来源：OpenAI

事实Kimi K3 继续作为近期最受关注的中国开源大模型

发布日期：2026-07-16；文中注明完整权重发布时间：2026-07-27

Moonshot 把 Kimi K3 定义为 2.8T 参数开源模型，已在 Kimi.com、Kimi Work、Kimi Code 与 API 提供使用，并把长程编码、视觉推理和工具调用列为核心卖点。

来源：Kimi Blog

事实DeepSeek V4 仍处在搜索与 Agent 场景的接入切换期

发布日期：2026-04-24；退役节点：2026-07-24 15:59 UTC

DeepSeek 把 V4-Pro 与 V4-Flash 定为当前主入口，突出 1M 默认上下文、思考/非思考双模式以及对 Claude Code、OpenClaw、OpenCode 等代理工具的接入优化。

来源：DeepSeek API Docs

事实NOAA 选择 Google Cloud 承载天气预测超级计算系统

发布日期：2026-07-27

来源：Google Blog

事实Meta 公布 AI 眼镜资助项目首批 30 个落地组织

发布日期：2026-07-27

Meta 宣布近 200 万美元 AI Glasses Impact Grants 的首批获奖方，涉及无障碍、施工培训、道路救援、农业和教育等场景，相关应用后续会接入 Ray-Ban Meta 眼镜。

来源：Meta Newsroom
