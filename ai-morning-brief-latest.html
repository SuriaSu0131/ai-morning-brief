11月3日Google Search 将为学生账号试点 Guided Learning

发布时间：2026-11-03；美国试点计划于11月内开始

Google 宣布把 Guided Learning 引入 Search：当系统识别到学生正在寻求作业帮助时，将用分步提示引导解题，而不是直接给出答案。首批试点面向部分美国学校，后续再扩展至其他学区。

来源：Google 官方博客

账号控制K‑12 学校若不启用 AI，学生账号也将无法使用 Google Search

官方公告与媒体说明：2026-11-03

Google 表示 Gemini、Gemini Notebook、Gemini in Classroom 与 Google Search 将默认对 K‑12 学生账号关闭，需管理员显式开启。Google 向媒体进一步说明，Search 与 AI 深度集成，学校不能在保留 Search 的同时完全关闭 AI 功能。

来源：Google 官方博客 · AP

11月4日中国版 Apple 智能计划今日开放开发者测试

公告时间：2026-10-31；计划开放时间：2026-11-04

来源：Apple 中国 · 千问 App

物理工程OpenAI 展示 Astra 与 Codex 的硬件设计流程

发布时间：2026-11-03

OpenAI 展示用 GPT‑6 Astra 与 Codex 完成外壳、PCB、固件和软件集成的测试设备：两名成员一周内完成设计，代工厂一个月内制作小批原型。制造公差、装配细节仍需多轮人工复核；OpenAI 同时宣布与 Mazda 开展车辆空气动力学与碰撞安全研究合作。

来源：OpenAI

安全评测OpenAI：智能体安全评测与生产行为存在10.2至37.4个百分点差距

发布时间：2026-11-03

OpenAI Alignment 团队比较六个模型在 Respecting Warnings 评测与匹配的 Codex 生产决策中的表现，发现评测成功率普遍低于生产。研究将差距部分归因于模型误判评测目标；结论来自 OpenAI 自有评测与生产样本。

来源：OpenAI Alignment Research

后训练OpenHands 与 Snowflake 将现有 Agent Harness 用于强化学习

发布时间：2026-11-03

OpenHands 与 Snowflake AI Research 公布后训练方案：开发者可沿用 OpenHands Agent SDK 配置和 Harbor 格式任务，无需在独立 RL 框架中重新实现 harness；训练算力由 Snowflake Cortex Training 提供。

来源：OpenHands 官方博客

长上下文评测Ai2 发布 StateBench，测试模型跟踪状态变化的能力

发布时间：2026-11-03

StateBench 用四级难度测试长文档中的状态追踪。Ai2 报告称，Gemini 3.8 Flash、Claude Opus 5.5、GPT‑6 Sol 与 Luna 在最长的高难样本上准确率降至 13% 或更低；直接训练的混合与 Gated DeltaNet 架构在部分任务上泛化更远。

来源：Ai2 / Hugging Face · GitHub
