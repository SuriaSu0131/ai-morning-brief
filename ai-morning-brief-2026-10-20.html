10月15日Google AI Search 增加更清晰的来源入口

发布时间：2026-10-15

来源：Google Blog

10月17日DeepSeek 开放网页搜索与抓取 API

发布时间：2026-10-17 00:00（北京时间）

来源：DeepSeek API 更新日志 · DeepSeek 官网

大公司动向

中国区过去24小时无同量级公司层面公开新增；MiniMax 与蚂蚁 inclusionAI 的模型发布列入下一栏。

官方披露Meta 公布 Prometheus 吉瓦级超集群进展

发布时间：2026-10-19 21:00（北京时间）

Meta 称 Prometheus 一期已建成并用于训练 Muse 系列模型，现由跨建筑的数十万张 GPU 组成，满规模目标约 100 万张 GPU。官方披露预训练有效算力利用率超过 85%，强化学习阶段超过 90%。

来源：Meta Engineering

治理安排Anthropic 承诺将 5% 股份投入公共利益基金

发布时间：2026-10-18

Anthropic 宣布设立公共利益基金，在股东批准后先投入公司 5% 的股份；公司估值每上升 50%，董事会可再增加 2%。基金可用于非营利组织捐赠或面向特定群体的直接分配。

来源：Anthropic Newsroom

产品与模型发布

中国模型MiniMax 正式推出 M3.1 Flash

发布时间：2026-10-19

MiniMax 发布 M3.1 Flash，面向智能体、编程、Computer Use 与网络安全任务。官方称线上推理速度接近上一代三倍、智能体任务综合使用成本降低 70%；模型已进入 API、M Plan 与 MiniMax Code，权重将稍后开放。

来源：MiniMax 官方博客

研究发布OpenAI 提升 COBOL、Fortran 等语言编码能力

发布时间：2026-10-19 20:00（北京时间）

OpenAI 发布低资源编程语言评测结果：GPT-6 Astra 在 MultiLangBench 的 20 种语言平均测试通过率为 87.4%；GPT-6.1 Sol 在 COBOL 迁移评测的高推理档达到 97.9%。评测套件与逐语言结果同步开放。

来源：OpenAI

高速推理Inception 发布扩散语言模型 Mercury 3

发布时间：2026-10-19

Inception 推出 Mercury 3，定位为低延迟旗舰扩散语言模型，支持 100 万 token 上下文。模型已在 Inception API、OpenRouter、Baseten 与 Vercel 上线，并兼容 OpenAI API 接口。

来源：Inception 官方博客 · OpenRouter（X）

视频模型fal 与 Black Forest Labs 推出 FLUX 3 Max

发布时间：2026-10-20 02:34（北京时间）

fal 宣布与 Black Forest Labs 联合发布后训练视频模型 FLUX 3 Max，可生成 10 秒、720/768p 视频；官方称单次生成约需 12 秒。第三方质量排名与成本数据均为发布方披露。

来源：fal（X）

计算平台AWS 发布 Trainium 原生 PyTorch 后端 TorchNeuron

发布时间：2026-10-19 20:45（北京时间）

AWS 与 PyTorch 发布 TorchNeuron，使常规 PyTorch 代码可通过单项配置切换运行在 Trainium 芯片上，减少专用重写。项目采用 Apache 2.0 协议，并于 10 月 20 日进入公开测试。

来源：PyTorch Blog · Reuters

开源语音蚂蚁 inclusionAI 开源 Ming-3.0-tts

发布时间：2026-10-19 15:03（北京时间）

inclusionAI 发布 Ming-3.0-tts，包含 0.5B Dense 与基于 Ling V3 的 Tiny 两个版本；后者总参数 7.9B、激活参数 1.3B。代码采用 MIT 许可证，权重可从 Hugging Face 与 ModelScope 获取。

来源：inclusionAI（GitHub）

来源：Google Blog

智能体架构Meta 公开 Thin Orchestrator 生产架构

发布时间：2026-10-19 23:30（北京时间）

Meta 的约 1300 行编排器只负责意图分类、字段收集、可靠性检查与路由，把 20 多项任务流程分派给 14 个上下文隔离的专项智能体；领域推理全部留在专项智能体内。

来源：Meta Engineering

医疗应用Numan 公布 AI 健康教练的评测优先方法

发布时间：2026-10-19 23:00（北京时间）

英国数字健康公司 Numan 介绍 AI 健康教练 Nu 的评测体系：按主题类别构建评分集，以较低成本模型模拟患者完成多轮对话，并让安全回归测试自动阻断不合格发布。

来源：LangChain Blog
