AI搜索专栏

过去24小时未见公开新增。DeepSeek、豆包、千问 App、夸克、Chrome、Google Search 均未见同量级公开官方入口变化；以下为近一周仍值得关注的变化，并保留原始日期。

近一周回看DeepSeek V4 Pro 登陆 API 与应用端

发布日期：2026-08-13

DeepSeek V4 Pro 在 APP、网页端和 API 同步上线，强调编码、工具调用和智能体工作流，1M 上下文版本随后由硅基流动提供 Day-0 支持。

来源：DeepSeek API 更新 · 硅基流动

近一周回看千问开源 Qwen3.8，模型变化延伸到检索入口

发布日期：2026-08-14

Qwen3.8-27B 采用 Apache 2.0 许可，原生支持 262K 上下文并可扩至 1M；这是一项模型层更新，尚未等同于千问 App 搜索入口改版。

来源：Alibaba Qwen（X） · Simon Willison

近一周回看Chrome Android 测试 Gemini 快捷入口

报道时间：2026-08-06

部分 Chrome Android 用户出现底部工具栏 Gemini 图标，可在浏览器内直接打开对话；目前仍是服务端灰度，不代表 Chrome 全量发布。

来源：Android Authority

大公司动向

公司公告OpenAI 因关键网络能力评估暂缓部分模型扩展

发布日期：2026-08-18

OpenAI 表示，受近期网络安全事件与即将推出的 Astra 模型影响，公司暂停最新部署模型的强化学习训练两周，并搁置最大规模前沿 RL 运行，同时加强思维链监控和多阶段分类器。

来源：OpenAI

研究发布Anthropic 公布 Claude 蛋白质设计实验

发布日期：2026-08-18

Anthropic 称 Claude Mythos Preview 与 Opus 4.8 针对 15 个靶点设计蛋白质结合剂，成功 14 个，命中率为 22.6% 至 35.1%；这是公司披露的实验结果，不等于临床验证。

来源：Anthropic Research

产品与模型发布

产品发布Claude 接入 Gmail 发信与 Google Drive 文件管理

发布日期：2026-08-18

付费用户可通过连接器让 Claude 起草并发送 Gmail 回复、管理 Drive 文件，并可设置发送前审批；能力边界取决于连接器授权。

来源：Claude（X）

产品发布OpenAI 推出 ChatGPT for Teens

发布日期：2026-08-18

面向 13 至 17 岁用户自动启用更强安全保护和家长控制，新增 Study Mode、作业提醒、测验可视化与 Study Hours，并与 CodeAI 合作开展青少年 AI 教育。

来源：OpenAI

开源发布Mojo 编译器与工具链全面开源

发布日期：2026-08-18

Modular 以 Apache 2.0（含 LLVM 例外）开源 Mojo 编译器、工具链和全部源码；编译器贡献计划预计在年底前开放，标准库此前已接受社区贡献。

来源：Modular
