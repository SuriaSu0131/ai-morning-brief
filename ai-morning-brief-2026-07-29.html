事实Google 继续用 AI Mode 强调“搜索即执行”与线下生活场景

发布日期：2026-07-28

Google 在最新 Search 官方文章中把 AI Mode 定位到找课程、买装备、订票与生成活动物料等线下场景，并继续强调可连接日历与第三方应用，说明 AI 搜索的重点仍在“从回答走向操作”。

来源：Google Blog

事实Google Search 的 AI Mode 已开始接入更多第三方应用

发布日期：2026-07-16

Google 宣布 AI Mode 在美国开始支持连接 Instacart、Canva、YouTube Music 等服务，用户可直接在搜索结果里加购物车、做设计或保存播放列表。

来源：Google Blog

事实Qwen Code 周更重新加入内建 web_search

发布日期：2026-07-23

Qwen Code 07-23 周报确认内建 web_search 回归，搜索结果会自动附带来源链接；这代表阿里系在“对话式检索 + Agent 工作流”上仍在持续补齐基础能力。

来源：Qwen Code Docs

事实DeepSeek 搜索与代理接入继续统一到 V4

发布日期：2026-04-24；旧模型退役生效：2026-07-24 15:59 UTC

DeepSeek 官方文档显示，deepseek-chat 与 deepseek-reasoner 已按计划退出，接入方需切换到 deepseek-v4-pro 或 deepseek-v4-flash，主打 1M 上下文和双模式推理。
